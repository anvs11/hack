# Автоматическое создание досье НПА

Статус: реализовано 2026-09-06.

После сохранения новой публикации collector проверяет заголовок и текст. Черновик
досье создаётся только при явном сочетании типа документа и его номера:

- федеральный закон `№ 321-ФЗ`;
- законопроект `№ 123456-8`;
- постановление Правительства РФ с номером;
- приказ поддерживаемого ведомства с номером.

Повторные упоминания одного документа не создают новые досье: публикации связываются
с существующей карточкой по нормализованному ключу. Для уже собранной базы есть
двухшаговая команда:

```bash
.venv/bin/python scripts/backfill_regulatory_cases.py
.venv/bin/python scripts/backfill_regulatory_cases.py --apply
```

Первая команда показывает совпадения и не изменяет данные. Вторая создаёт или
досвязывает черновики.

## Граница доверия

Публикация из СМИ, RSS или Telegram не подтверждает юридический статус документа.
Поэтому автоматически созданное досье получает:

- `current_stage=draft`;
- `origin=automatic`;
- `needs_review=true`;
- ссылки на найденные публикации;
- ни одного автоматически созданного `LifecycleEvent`.

Специалист может исправить название, номер и ответственного прямо в досье. Флаг
проверки снимается только после ручного добавления официально подтверждённого
lifecycle event. Стадия меняется по зафиксированной матрице переходов.

Текущие правила не считаются измеренной полнотой распознавания всех видов НПА.
Новые шаблоны следует добавлять после проверки на реальном размеченном датасете.
