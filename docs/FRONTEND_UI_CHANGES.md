# Изменения интерфейса

## 2026-09-06 — автодосье и проверка реквизитов НПА

- Автоматически найденное досье помечается «Требует проверки».
- В карточке специалист может исправить название и номер документа; после сохранения
  он становится ответственным за досье.
- Редактирование реквизитов не меняет юридическую стадию. Она подтверждается только
  отдельным lifecycle event с официальной ссылкой.

## 2026-09-06 — просмотр первоисточников

- Для одной ссылки вместо раскрывающегося списка показано прямое действие
  «Открыть первоисточник».
- Для двух и более ссылок остаётся список «Первоисточники», где видны название
  источника, дата материала и отметка главного источника.
- Список теперь раскрывается вправо от своей кнопки и не уезжает за левую границу
  страницы на узком экране.
- API и модель `source_references` не менялись.

## 2026-09-06 — только реальные данные в обычном запуске

- Удалён публичный endpoint импорта demo seed и автоматический запуск MSW без
  явного тестового окружения.
- В обычном локальном и серверном запуске frontend всегда читает рабочий API с
  реальными собранными или вручную добавленными материалами.
- Поля и метки `is_demo`, тестовые типы источников и технические demo-badge удалены
  из пользовательского контракта и интерфейса.
- В досье документа скрыты внутренние ID, англоязычные служебные подписи и поле
  ручного ввода автора; автор берётся из текущей подтверждённой identity.
- Синтетические fixtures сохранены только для unit/E2E-тестов во временной БД.

## 2026-09-06 — последовательная карточка публикации

- Блоки «Исходный материал» и «AI-анализ» больше не стоят в двух колонках.
- Карточка читается сверху вниз: сначала исходник, затем выбранная версия AI.
- Подписи явно обозначают «Шаг 1» и «Шаг 2».
- Ширина исходного текста ограничена до `120ch`, чтобы длинные строки оставались
  читаемыми на широком экране.
- API, модели данных и OpenAPI-контракт не менялись.

Причина: исходный материал и AI-анализ являются последовательными этапами проверки,
а не двумя равноправными панелями для постоянного построчного сравнения.

## 2026-09-06 — личные режимы и одна карточка события

- В шапке остались два однозначных режима «Кратко» и «Подробно»; выбор хранится в профиле
  пользователя через `GET/PATCH /api/me`, а localStorage служит fallback.
- Любая роль может выбрать любой режим. Роль влияет на права, режим — только на
  плотность и детализацию представления.
- Мониторинг сортируется по дате публикации от новых к старым и обновляет список
  каждые 15 минут.
- Экран похожих публикаций и блок похожих карточек удалены. Одна карточка события
  показывает раскрываемый список всех первоисточников.
- Непроверенное смысловое совпадение теперь появляется внутри самой карточки:
  специалист может объединить источники, оставить материалы связанными или
  отметить их разными событиями. Числовой cosine score не показывается.
- Из основного UI убраны demo-ID, технический API badge и числовой индекс важности.
  Названия модели, анализатора, prompt и внутренней схемы не показываются.
- Ручной и автоматический отчёт можно отправить сообщением в Telegram из Mini App.
- Автоматическую доставку новых релевантных AI-анализов можно включить на странице
  отчёта и ограничить минимальным приоритетом.
- Пользовательский раздел «Кейсы НПА» переименован в «Нормативные документы», а
  карточка — в «досье документа»; API-имя `RegulatoryCase` не изменилось.
- Публикация без AI-версии показывает «AI-анализ в очереди», а не фиктивные
  неопределённые категорию и приоритет.
- Автоотчёт начинает отсчёт с момента включения и не отправляет весь старый архив.
  Попавшие в отчёт версии записываются как доставленные и не повторяются.
