# Бенчмаркинг продукта: определение стандартов через анализ конкурентов

**Продукт:** ИИ-аналитический центр для PR/GR — автоматический сбор, саммаризация,
категоризация и приоритизация отраслевых новостей, НПА и Telegram-каналов в едином
интерфейсе с управлением источниками и данными.
**Кейсодатель:** GS Labs (электроника, телеком, цифровая экономика).

**Вход для корректировок:**
- ориентиры метрик куратора (время/качество, жёстких порогов намеренно не фиксировали);
- текущий процесс кейсодателя — Excel «Реестр оценки влияния НПА и отраслевых событий»
  (46 карточек, методика К1–К6 и Н1–Н4);
- комментарий одногруппника: Excel as is — неудобно и ДОЛГО, не референс UX.

## 1. Выбор конкурентов

### Критерии выбора
Кейс закрывает три слоя информации: СМИ, регуляторика (НПА), Telegram. Поэтому смотрим
прямые мониторинги СМИ, смежные решения (НПА-мониторинг, TG-аналитика, AI-ленты
аналитика) и — теперь с конкретными данными — текущий внутренний процесс (Excel-реестр).
Для учебного проекта берём решения с открытыми данными; Excel-реестр берём как эталон
«текущего процесса» с реальными издержками ручного труда.

## 3. Анализ и сравнение

### JTBD-рамка (из пакета)
**Подработа (кейс):** «собрать дайджест/обновить реестр, не пропустив важное»
**Большая работа (продукт):** «вовремя заметить регуляторное/рыночное изменение и
отреагировать до того, как оно стало риском или упущенной возможностью»

Это объясняет, почему продукт живёт на большой работе: мониторинги закрывают подработку
(сбор), но не большую работу (своевременная реакция). Наш вклад — в мосте между ними.

### Ответы на ключевые вопросы
1. **Обязательные функции (анализ конкурентов + ориентиры куратора):**
   - Сбор из трёх слоёв (СМИ/НПА/TG) со SLA доставки: ≤15 мин после публикации, сайты регуляторов — до 1 часа;
   - Скоуп MVP: ядро — GR-контур (НПА + отраслевые новости + методика К1–К6/Н1–Н4); 
   - PR-контур (СМИ/репутация) — тем же конвейером, категории «репутация/конкуренты/тренды» второй очередью.
   - LLM-саммари 3–5 предложений + сущности; фактологичность: в саммари нет фактов, которых нет в оригинале;
   - Дедупликация: дубли одной новости схлопнуты в одну карточку;
   - Категоризация по важности с точностью ≥80% и жёстким правилом «критичное ≠ низкий»;
   - Приоритизация по методике заказчика (К1–К6 / Н1–Н4), категории в его языке;
   - Дашборд: лента, фильтры, поиск и фильтры отвечают <1 сек, ссылка на оригинал;
   - Обработка одной публикации 10–15 сек;
   - CRUD источников и данных (оцифровка «ручных ячеек» Excel) + ручное добавление;
   - Утренний дайджест + экспорт (почта/Telegram/CSV).
2. **Функции отличия:**
   - Готовый материал для решения, а не регистрация упоминаний: саммари + скоринг по методике + «почему важно» (разложение по К1–К6);
   - Единый поток СМИ+НПА+TG (у конкурентов разорвано по продуктам);
   - Методика заказчика как **конфигурация**, а не хардкод: ядро переносимо на другие отрасли;
   - Асимметрия к риску: приоритизация, исключающая провал критичных в «низкий» (аналог перцентиля из прошлого проекта);
   - Human-in-the-loop: эксперт валидирует автоскоринг — методика сохранена, ручной труд убран;
   - Ролевые профили (PR/GR/Руководитель) в едином интерфейсе: стартовый набор источников, категории и алерты конфигурируются под роль, но интерфейс один (vs разные продукты у конкурентов для разных ролей).
   - Непрерывный мониторинг вместо эпизодических обновлений файла.
3. **Недостатки конкурентов, которые устраняем:**
   - Excel: вручную, долго, эпизодично, без дедупа/саммари/алертов → автоматизируем всё; UX Excel — антипаттерн, не референс;
   - Медиалогия/СКАН: нет готового дайджеста и НПА-методики → у нас есть;
   - КонсультантПлюс/Гарант: «что изменилось» без «что значит для бизнеса» → у нас суть + скоринг;
   - Meltwater: цена, слабая РУ-регуляторика, cloud-only → on-prem/РУ-LLM, цена для команды;
   - Feedly: нет РУ-специфики и НПА → у нас есть.
4. **Стратегии монетизации:**
   - Пилот с кейсодателем: 0 ₽ за 2–4 недели в обмен на метрики и кейс;
   - Масштабирование: командная подписка 30–60 тыс. ₽/мес (до 5 пользователей) — дешевле FTE-часов, сопоставимо с Brand Analytics;
   - Enterprise: по запросу (on-prem, РУ-LLM, интеграции);
   - Обоснование: подписка доминирует в нише; пилот → подписка снижает риск клиента.
5. **Улучшения пользовательского опыта:**
   - Утренний разбор суточной повестки — 10–15 минут вместо часов (ключевая цифра куратора);
   - Очередь «высокое/критическое» сначала + объяснение балла;
   - Валидация/правка в один клик (ручные ячейки Excel становятся полями продукта);
   - Автофлаги эскалации и сроки по методике;
   - Кнопка «Дайджест руководителю».
6. **Ключевые характеристики конкурентоспособности:** см. раздел 4.4 — ориентиры куратора + продуктовые гипотезы.
7. **Why now — почему это возможно именно сейчас?**
   - LLM-саммаризация и извлечение сущностей на русском стали рабочими, включая
     открытые модели для on-prem (требование регулируемых компаний);
   - стоимость инференса упала: сотни документов в день — копейки;
   - tool calling / MCP — стандартное подключение источников (RSS/сайты/TG) без
     кастомных интеграций — чего не было у аналогов поколения «мониторингов»;
   - тренд подтверждён лидером рынка: Meltwater за последний год ввёл AI-саммари
     (Mira) — спрос на слой интеллекта реален, но ниша РУ-регуляторики свободна.
8. **Порядок величины рынка (оценка порядка, не точность; RAT-дисциплина):**
   - Регулируемые отрасли РФ (банки ~400, телеком, ИТ с аккредитацией, энергетика,
     фарма, ритейл) — порядок 3–5 тыс. компаний с активной GR/PR-функцией;
   - ×2–6 специалистов на компанию → порядок 10–30 тыс. носителей проблемы;
   - Путь верификации: справочники (СПАРК/Руспрофайл по ОКВЭД), вакансии
     «GR/PR-аналитик», опрос сокурсников (345 человек на потоке — доступная выборка
     «таких же пользователей из других компаний»).

## 4. Определение стандартов

### 1. Минимальные требования к функциональности
- Сбор из трёх категорий источников со SLA доставки (≤15 мин / ≤1 ч) и адаптерами + fallback на RSS;
- LLM-саммаризация 3–5 предложений + сущности; фактологичность саммари;
- Дедупликация новостей в одну карточку;
- Категоризация по важности (≥80%) + правило «критичное ≠ низкий»;
- Скоринг по методике К1–К6 / Н1–Н4, категории и реакции в языке заказчика;
- Дашборд: лента, фильтры, поиск <1 сек (текст/теги/сущности), ссылка на оригинал;
- CRUD источников + правка метаданных (стадия, баллы, флаг, действия, сроки) + ручное добавление; 
- Ролевые профили при регистрации (PR/GR/Руководитель) с автоконфигурацией источников;
- Утренний дайджест и экспорт (почта/Telegram/CSV);
- Eval-скрипт на датасете 50+: accuracy по важности, «критичное→низкий» = 0, дедуп, фактологичность.

### 2. Ключевые конкурентные преимущества
- Готовый материал для решения (саммари + скоринг + «почему важно»), а не лента упоминаний;
- Единый поток СМИ+НПА+TG;
- Методика заказчика как конфигурация: доверие с первого дня + переносимость на другие отрасли;
- Асимметрия к риску: критичные материалы не проваливаются в «низкий»;
- Human-in-the-loop: методика сохранена, ручной труд убран;
- Простота внедрения: источник за ≤5 мин, пилот за ≤1 недели (vs месяцы у enterprise и недели у Excel).
