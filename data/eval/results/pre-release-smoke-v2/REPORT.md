# Pre-release local smoke v2

Дата: 2026-09-05
Quality claim: запрещён — это проверка связности и регрессии, а не качества модели.

## Проверено

- API v0.4.0 возвращает `importance_score` 0–18, шесть именованных критериев и
  четыре именованных hard signal;
- AI сохраняет только `proposed_priority`, решение специалиста хранится отдельно;
- неизвестные оценки остаются `null` и требуют проверки;
- worker выполняет первый сбор сразу и затем повторяет его каждые 1800 секунд;
- Telegram frontend дожидается загрузки официального SDK, отправляет raw `initData`
  на backend и показывает подтверждённого пользователя;
- отсутствие inference-настроек показывается человеку понятным сообщением без имён
  переменных окружения.

## Измерения

- текущая локальная БД: 18 источников, 385 публикаций, 12 версий анализа;
- первый проход worker: 13/13 источников успешны, 311 материалов получено, 3 новых,
  307 уже известных по ID/URL, 1 совпадение текста;
- backend: 173 теста прошли;
- frontend: 127 тестов прошли;
- typecheck и production build прошли;
- lint: 0 ошибок, 10 предупреждений.

## Внешние блокеры

Telegram token и signed initData проверены, но реальный Mini App пока не является
полностью проверенным сценарием: нужны публичный HTTPS URL и BotFather Web App
configuration. Live AI через CloudCompute Qwen проверен отдельным smoke на одной
публикации; это не quality benchmark и не SLA.
