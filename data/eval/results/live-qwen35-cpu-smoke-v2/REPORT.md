## Сценарий

Backend был запущен с `HACK_ANALYZER_MODE=huggingface_local`, моделью
`Qwen/Qwen3.5-0.8B`, лимитом входа 6000 символов и лимитом генерации 384 токена.
Через реальный HTTP API был запрошен новый анализ публикации
`publication-ca349ada4e1e4f92a3d9e113a93185bf`.

```bash
curl --max-time 300 \
  -X POST \
  http://127.0.0.1:8000/api/publications/publication-ca349ada4e1e4f92a3d9e113a93185bf/analyses
```

## Результат

- HTTP-ответ не получен за 300.0061 секунды;
- новая `AnalysisVersion` не создана;
- процесс был остановлен после клиентского timeout;
- проверена только связность local Hugging Face пути и его фактическая задержка;
- качество саммари, извлечения и приоритизации этим запуском не измерено.

**Вывод:** на текущем локальном CPU этот режим не подходит для интерактивной кнопки.
Для demo нужен быстрый внешний OpenAI-compatible endpoint или отдельный inference
server. Replay остаётся только воспроизводимым demo/eval режимом и не подменяет live
анализ пользовательской публикации.
